# Code of Conduct

## Our pledge

We want this list to be useful to anyone working on European cybersecurity:
regulators, CSIRT staff, maintainers, students, regardless of background,
nationality, employer, or how long they have been in the field.

## Expected behaviour

- Argue about entries, not about people. "This fails the EU relevance rule
  because the page never mentions an EU scheme" is a review. "You clearly don't
  know this area" is not.
- Assume the contributor read the rules and disagreed, rather than that they
  ignored them.
- Accept correction. Everyone here will occasionally add something that turns out
  to be wrong; the list works because that gets fixed without drama.
- Write descriptions in plain English. Many contributors and readers are not
  native speakers, and a good chunk of the source material is not in English
  either.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, deliberate disruption of
review discussions, sustained off-topic political argument, and publishing
private information without permission.

**Vendor promotion.** Using pull requests or issues to market a product is
unacceptable behaviour, not merely an out-of-scope entry. Disclose any affiliation
with a resource you propose.

## Enforcement

Report problems by opening an issue or contacting the maintainers privately.
Reports are handled confidentially. Maintainers may edit, remove or reject
contributions, and may block accounts, for behaviour that breaches this document.

This Code of Conduct adapts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.
