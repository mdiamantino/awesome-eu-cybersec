# Security

This repository holds a curated list of links and a small amount of Python
tooling. It processes no user data and runs no services.

## Reporting a problem

- **A link here points somewhere harmful**, a hijacked domain, a typosquat, a
  compromised page. Open an issue immediately using the "Report a problem"
  template, or contact the maintainers privately if disclosing it publicly would
  put readers at risk. This is the report we care most about.
- **A vulnerability in the tooling under `scripts/`**, open an issue. The scripts
  fetch URLs listed in this repository and write files inside it; treat anything
  that escapes that as a real finding.

## What this list is not

Inclusion is not an endorsement, an audit, or a statement that a tool is secure or
fit for your purpose. Entries are verified for existence, identity and EU
relevance, nothing more. Evaluate anything you deploy yourself, and check
certification claims against the issuing authority's own registry rather than
against this list.
